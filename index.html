Hướng Dẫn Kết Nối Google Sheets & Mã Apps Script (JS)

Cách lấy Sheet ID hoặc tạo Web App API trả về JSON tự động

⚡ Cách 1 (Dễ nhất - Không cần lập trình): Dùng Google Sheet ID trực tiếp
  1. Mở bảng tính Google Sheets của bạn.
  2. Nhấn nút Chia sẻ (Share) ở góc phải trên > Chọn "Bất kỳ ai có đường liên kết" (Quyền: Người xem).
  3. Sao chép Sheet ID từ thanh địa chỉ trình duyệt:
    https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit
  4. Dán đoạn ID trên (hoặc toàn bộ URL) vào ô nhập liệu rồi nhấn "Tải & Xem trước". Hệ thống sẽ tự động đọc trực tiếp!
🚀 Cách 2 (Nâng cao): Google Apps Script Web App (JSON API)

Trong Google Sheets của bạn: Nhấn menu Tiện ích mở rộng (Extensions) > Apps Script, xóa hết mã cũ và dán đoạn mã JavaScript bên dưới, sau đó bấm Triển khai (Deploy) > Tùy chọn triển khai mới > Ứng dụng web (Web app) (Truy cập: Bất kỳ ai): 

function doGet(e) {
  var sheetName = (e && e.parameter && e.parameter.sheet) ? e.parameter.sheet : "Sheet1";
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName(sheetName) || ss.getSheets()[0];
  var data = sheet.getDataRange().getValues();
  if (!data || data.length === 0) {
    return ContentService.createTextOutput(JSON.stringify({status: "empty", rows: []}))
      .setMimeType(ContentService.MimeType.JSON);
  }
  
  var headers = data[0];
  var rows = [];
  for (var i = 1; i < data.length; i++) {
    var row = data[i];
    var obj = {};
    for (var j = 0; j < headers.length; j++) {
      var key = String(headers[j]).trim();
      obj[key] = (row[j] !== undefined && row[j] !== null) ? String(row[j]).trim() : "";
    }
    rows.push(obj);
  }
  
  var result = {
    status: "success",
    sheet: sheet.getName(),
    total: rows.length,
    rows: rows
  };
  
  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}

Sau khi Deploy, bạn sao chép URL Ứng dụng web nhận được và dán vào ô nhập liệu của website.
